# LingEx Public Data

This repository distributes reviewed open-data and ShareAlike packages used or
produced by LingEx.

There is no single data licence for the whole repository. Each package is
licensed separately through its `manifest.json`, `LICENSE.txt`,
`ATTRIBUTION.md`, and `CHANGES.md`.

Large archives should be attached to GitHub Releases. Only packages approved
through rights, proprietary-exclusion, privacy, security and technical review
may be published.
